Удаленное управление ПК через Radmin VPN

Radmin VPN полностью интегрирован с программой Radmin Viewer / Server для управления ПК на расстоянии.

Для подключения достаточно кликнуть правой кнопкой мыши по нужному компьютеру в списке сети Radmin VPN и выбрать пункт Управление или Просмотр.
